# gridpath-web (source)

The browser half of the [`gridpath`](../gridpath) package: the embeddable
spreadsheet, its engine worker and the agent tools. `npm run build` writes it
into `../gridpath/dist/web`, which `gridpath` publishes as its main export.
Not published on its own; the documentation is in
[`packages/gridpath/README.md`](../gridpath/README.md#in-your-web-app).
