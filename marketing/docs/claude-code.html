Docs / Claude Code

Claude Code.

One command registers GridPath as an MCP server. Claude Code then has every GridPath tool, and every edit comes back with a review link.

Install

claude mcp add gridpath -- npx -y gridpath mcp --review-required

This registers the server for the current project. To make it available in every project, add the user scope flag:

claude mcp add -s user gridpath -- npx -y gridpath mcp --review-required

npx -y fetches the latest published version on first run and caches it. Node 20 or newer is required.

Check it is running

Inside Claude Code, run /mcp. GridPath should be listed as connected with its tools. On startup the server prints one line to stderr naming the allowed folders and the review server address.

First edit

Ask for a change by file path:

In ~/models/forecast.xlsx, add a Q3 2026 column after Q2 and extend every formula.

Claude will call describe_workbook and find_rows to orient, then write the change. The result includes a review_url, and the server's instructions tell the agent to show it to you. Open the link to see the changed cells, then save from the page.

Why review-required

With --review-required, save_workbook does not write. It returns the review link and the agent hands it to you. Nothing reaches disk until you accept and save on the review page. Drop the flag if you want the agent to save on its own; the review link still comes back with every write so you can check afterwards. See Review before save.

Limiting folders

By default the server can open files anywhere under your home directory. To box it in:

claude mcp add gridpath -- npx -y gridpath mcp --review-required --allow ~/models ~/clients

Files outside the allowed folders are refused, and the error tells the agent not to copy the file somewhere else to work around it.

Remove

claude mcp remove gridpath
