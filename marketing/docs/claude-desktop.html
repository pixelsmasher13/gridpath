Docs / Claude Desktop

Claude Desktop.

Download one file and open it. Claude Desktop installs GridPath as an extension, with Node bundled, so there is nothing else to set up.

Install

  1. Download the latest gridpath-<version>.mcpb from the releases page.
  2. Open the file. Claude Desktop shows an install dialog with two settings.
  3. Limit Claude to these folders is optional. Leave it as is to allow your whole home directory.
  4. Require review before saving is on by default. Keep it on: Claude cannot write the file, you accept and save on the review page it links you to.
  5. Click install.

Claude Desktop shows its standard "not verified" warning for any extension installed from a file. The source is public, and nothing is written to any file until you accept and save on the review page.

First edit

Start a chat and name the file by path:

Open ~/Documents/budget.xlsx and add a 5% contingency line under each department's total.

Claude reads the structure, writes the change as a pending batch, and replies with a review link. Click it. The page shows the workbook with changed cells highlighted and a panel of pending batches. Accept, reject, then Save to file or Save as a copy.

Changing the settings later

Open Claude Desktop's extensions settings, find GridPath, and edit the folder list or the review setting. The review setting maps to the server's --review-required flag; see CLI options.

If a chat ends with changes pending

Pending batches are stored next to the workbook in a .gridpath folder, so they survive the chat ending. The next time Claude opens the same file they are picked up, and the review link shows them. You can also reopen the review page from a terminal if you have Node installed:

npx -y gridpath review ~/Documents/budget.xlsx

Found a mistake? Open an issue or email support@gridpath.dev.
