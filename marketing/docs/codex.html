Docs / Codex

Codex.

Three lines in ~/.codex/config.toml register GridPath with Codex.

Install

[mcp_servers.gridpath]
command = "npx"
args = ["-y", "gridpath", "mcp", "--review-required"]

Restart Codex. Node 20 or newer must be available on the PATH Codex uses.

First edit

In ~/reports/kpis.xlsx, add a YoY growth column next to each metric on the Summary sheet, as formulas.

Codex reads the structure with describe_workbook and find_rows, writes the formulas, and the result includes a review_url. Open it to see each changed cell before and after, then save from the page.

Limiting folders

Append "--allow", "/path/to/folder" to args, repeating the path for each folder. The default is your home directory. Files outside the allowed folders are refused.

Gemini CLI, Windsurf, VS Code

Any MCP host that launches a stdio server works with the same command and arguments. Put npx as the command and ["-y", "gridpath", "mcp", "--review-required"] as the arguments in that host's MCP configuration.
