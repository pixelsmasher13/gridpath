A spreadsheet your users already know how to use

On top of the files they already have. Apache-2.0.

Saves the file back intact

A save patches only the parts of the .xlsx the session changed; charts, pivots, macros, names and custom XML come back byte-identical. On a 1.4 MB analyst model, 75 of 76 parts were unchanged and nothing was lost; the other embeddable spreadsheets we measured dropped custom XML and printer settings, or most of the defined names.

A real calculation engine

A Rust engine (an IronCalc fork, compiled to WebAssembly) runs in a Web Worker: dynamic arrays, LET and LAMBDA, XLOOKUP, the IFS family, AGGREGATE. A 1.4 MB, 55,000-formula model is usable in 0.6 s. A model with 2.3 million cells is usable in 4 s and fully recalculated in 11 s; in the same test SpreadJS crashed the tab and the Handsontable stack took 11 minutes.

Toolbar and saving built in

Formatting, number formats, insert and delete, sort, filter, freeze. Autosave with "Saving… / Saved", reopen where you left off, recent workbooks, version history with restore, and Download as .xlsx. In the browser by default, or to your backend through onSave or a store of your own.

AI that asks before it saves

Give sheet.ai.tools() to your model; its edits land highlighted, and the AI changes panel lists each one (before → after) to accept or reject. Nothing an agent did is saved until the user accepts it.

Your model, your key

The model call happens on your server with your key; the tools run in the browser, where the workbook is. GridPath never sees a key or a file.

No configuration

Next.js (Turbopack and webpack), Vite and webpack bundle the worker and engine on their own. React component or createSpreadsheet(el) for any page.

Two files

The spreadsheet

// app/Sheet.tsx
"use client";
import { Spreadsheet } from "gridpath";

export function Sheet({ file }: { file?: ArrayBuffer }) {
  return (
    <div style={{ height: 600 }}>
      <Spreadsheet file={file} fileName="Budget.xlsx" />
    </div>
  );
}

That's a working spreadsheet with a toolbar, autosave and version history. Pass onSave to keep the bytes on your side.

AI, with your key (optional)

// app/api/agent/route.ts
import Anthropic from "@anthropic-ai/sdk";
import { AGENT_INSTRUCTIONS, agentTools } from "gridpath/agent";

export async function POST(req: Request) {
  const { messages } = await req.json();
  const reply = await new Anthropic().messages.create({
    model: "claude-opus-5-5",
    max_tokens: 16000,
    system: AGENT_INSTRUCTIONS,
    tools: agentTools(),
    messages,
  });
  return Response.json(reply);
}

Add your own auth and rate limits. In the browser, run each tool call with sheet.ai.run(name, input) and send the results back; the loop is twenty lines.

Measured in Chromium on an M2 Pro against SpreadJS 19.2 and Handsontable 18.1 with HyperFormula and ExcelJS; method and full results. The two real models are private; the benchmark reads your own copies.
