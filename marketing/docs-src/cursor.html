Cursor.

Install with one click, or add three lines to mcp.json. Cursor's agent then edits real Excel files through GridPath and gives you a review link before anything is saved.

One-click install

Add to Cursor

This opens Cursor and pre-fills the server configuration below. Confirm to install.

Or edit mcp.json

For one project, create .cursor/mcp.json in the project root. For every project, use ~/.cursor/mcp.json.

{
  "mcpServers": {
    "gridpath": {
      "command": "npx",
      "args": ["-y", "gridpath", "mcp", "--review-required"]
    }
  }
}

Node 20 or newer must be on Cursor's PATH. Open Cursor's MCP settings to confirm GridPath shows as connected with its tools listed.

First edit

In agent mode, ask for a change and give the file path:

In data/pipeline.xlsx, flag every row on the Deals sheet where Stage is "Closed Lost" and add a Lost Reason column.

The agent calls GridPath's read tools, writes the change, and the tool result contains a review_url. Open it, check the changed cells, and save from the page.

Limiting folders

Add "--allow", "./data" or any absolute path to args to restrict which folders the server may open. The default is your home directory. See CLI options.
